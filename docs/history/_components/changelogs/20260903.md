## *RZ Linux BSP Plus for Kernel 6.12 v4.0*

{% endif %}

2026/09/03
{: .right .small }

RZ Linux BSP Plus for Kernel 6.12 v4.0 is available.

Target Devices : RZ/G2L, RZ/G2LC, RZ/G2UL, RZ/G3S, RZ/G3L, RZ/G3SE, RZ/T2H, RZ/N2H

!!! note

    * RZ/G3L and RZ/G3SE are newly supported in this update.

    * This update is only for adding supported devices. There are no feature updates for the devices that were supported in v3.0.
